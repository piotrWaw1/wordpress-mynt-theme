# Requirde plugins

1. Secure Custom Fields
2. Contact Form 7
3. Safe SVG

# Config after plugins installation

## Secure Custom Fields

1. Go to `/config` and copy `scf-export.json`
2. On wordpress admin panel go to SCF->Tools
3. Click import json

## Contact Form 7

1. Go to `/config`
2. Open file `contact-form.txt`
3. Copy it content
4. Paste it in admin panel Contact->Contact Forms and paste it
